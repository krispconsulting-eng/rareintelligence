# MasterClass Executive

Kris Pierce's MasterClass Executive programme. First project: the Kris Pierce Toolkit
video, in `toolkit-video/`.

`toolkit-video/kris-pierce-toolkit-sound.mp4` is the finished cut: vertical 9:16, 28
seconds, with sound. Twelve official lab buttons drop one at a time into a black
leather bag marked KRIS PIERCE TOOLKIT, then the camera pulls back to leave it standing
small under one spotlight. A silent version sits beside it for adding a music track;
`toolkit-video/README.md` has the beat map and everything else.

The twelve lab artworks and the bag sit at the top of this folder, as uploaded.

## A note on this repository

`rareintelligence` is public and is deployed as a live site, so everything here is
publicly reachable, MasterClass's lab artwork included. If that should not be public,
move `masterclass/` into a private repository of its own rather than deleting files
from this one, since they stay in the git history either way.
