# MasterClass Executive

Working files for Kris Pierce's MasterClass Executive programme. First project: the
Kris Pierce Toolkit video, a short vertical film in which twelve official lab buttons
drop into a bag marked KRIS PIERCE TOOLKIT, each one a capability added to the sector
expertise Kris already brings to her work.

| Path | What it is |
|---|---|
| `toolkit-video/README.md` | The brief: direction, format, checklist. |
| `toolkit-video/sequence.md` | The timeline, scene by scene. |
| `toolkit-video/prompts.md` | Background prompts for the generator. |
| `toolkit-video/edit-guide.md` | Layers, the drop animation, music, captions. |
| `toolkit-video/voiceover.md` | Narration scripts and timing. |
| `toolkit-video/post.md` | Draft of the accompanying post. |
| `toolkit-video/assets/` | Asset conventions and the manifest of the bag and the twelve buttons. |

## Where this should live

This folder is a holding place. The intended home is a private repository of its own,
`krispconsulting-eng/masterclass`, because the video uses MasterClass's official
lab-button artwork and that artwork should not sit in a public repository. This
repository is public and is deployed as a static site, so everything committed here is
publicly reachable.

Until the private repository exists, keep text here and keep the artwork out of git
(see `toolkit-video/assets/README.md`). To move the project, copy `toolkit-video/` into
the new repository's root, commit it there, then delete this folder.
